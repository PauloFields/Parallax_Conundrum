# Parallax Conundrum

Visual simulation of a specific Magic: The Gathering interaction.

## Initial State

- Opalescence on the battlefield.
- Player A controls a Parallax Wave with five fading counters.
- Player B controls a Parallax Wave with five fading counters.
- Player A has priority.

## Planned Features

- Visual battlefield.
- Stack representation.
- Priority and ability resolution.
- Reset to the initial state.
